## 📌 Project Description

NEXACHAIN AI backend is built using MERN Stack technologies.

It provides APIs for:

- User Authentication
- JWT Security
- Investment Management
- Dashboard Data
- Referral System
- ROI Calculation
- Cron Scheduler


## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- node-cron
